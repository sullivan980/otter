# 语言 / English UI

设置 → 通用 → 语言：跟随系统 / 中文 / English；切换后需重启 Otter。

## 已英文化
- 侧栏导航、窗口标题与分区说明
- 清理页主要状态、空状态、按钮、分类名
- HUD：状态、指标名、网络、TOP 进程、按钮、退出进程确认
- 菜单栏右键菜单
- 设置页各分区标题与语言选择
