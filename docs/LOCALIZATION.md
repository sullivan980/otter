# 语言 / English UI

设置 → 通用 → 语言：跟随系统 / 中文 / English；切换后需重启 Otter。

## 已英文化
- 侧栏导航、窗口标题与分区说明
- 清理页主要状态、空状态、按钮、分类名
- HUD：状态、指标名、网络、TOP 进程、按钮、退出进程确认
- 菜单栏右键菜单
- 设置页各分区标题与语言选择

## 设置页也已英文化
- 主题名称/描述、按钮、设置项标题与说明、Otter 回收站、清理规则、提醒、
  阈值告警、诊断、更新、白名单、权限、插件管理。

## 仍为中文
- 底层错误/日志文案、部分系统通知（后续可继续补）。

## 实现
- L10n：L("中文","English")，读取 Prefs.language；
- 调试可用 OTTER_LANG=en / zh 覆盖；
- 自测 OTTER_SELFTEST=i18n。
