# 阈值告警 / 进程管理

## 阈值告警
设置 → 阈值告警（默认关闭）：

- CPU / 内存 / 磁盘三个阈值（50–100%，步进 5%）
- 持续时间：10 / 30 / 60 秒
- 连续超过阈值才发通知；冷却 10 分钟内不重复
- 通知点击打开主界面

## 提醒
设置 → 提醒：

- 低磁盘提醒：磁盘超过告警阈值时每天最多提醒一次
- 定期清理提醒：关闭 / 7 / 14 / 30 天（距上次清理）
- 都只发通知，不自动清理

## 进程管理
HUD → TOP 进程列表：

- 右键进程 → 「退出」/「强制退出」
- 退出发送 SIGTERM，强制退出发送 SIGKILL
- 操作前有确认框；结果会显示在应用内结果卡
- 不提供对 PID ≤ 1 的系统进程操作
