# 桌面实时小组件

菜单栏右键 → 桌面小组件；或 设置 → 桌面小组件。

## 为什么不是 WidgetKit
macOS 的 WidgetKit 刷新由系统限流（通常分钟级），无法展示秒级 CPU。
因此 Otter 用无边框浮层实现桌面小组件，数据与菜单栏/HUD 同源（1–2 秒），
可拖动、位置会记住、可关。

## 显示内容
- CPU 总占用（大号数字）+ 8 核负载条
- 内存 / 磁盘占用（带细进度条）
- 上传 / 下载速率
- 关闭按钮

## 设置
- 显示桌面小组件（开关）
- 始终置顶（关闭后只在普通窗口层）

## 测试
OTTER_SHOW_WIDGET=1 启动即可直接显示（配合 /tmp/otter-test-flags.json 的 noOnboard）。
