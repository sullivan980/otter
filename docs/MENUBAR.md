# 菜单栏显示（样式插件）

## 目录
- 用户样式：~/Library/Application Support/Otter/menubar/*.json
- 保存后 0.5 秒自动重载；设置页也有「打开样式目录 / 重新加载」。

## 内置 5 种
| id | 名称 | 预览（CPU 42% / 内存 61%） |
|---|---|---|
| value | 纯数值 | 42% 61% |
| label | 带名称 | CPU 42% 内存 61% |
| icon | 图标 + 数值 | 图标 42% 图标 61% |
| dot | 中点分隔 | 42% · 61% |
| trend | 数值 + 趋势 | 单指标时在数值后加 8 格趋势 |

## 自定义样式 JSON
    {
      "id": "compact",
      "name": "紧凑点",
      "showLabels": false,
      "showIcons": false,
      "showTrend": false,
      "separator": " · "
    }

- id 与内置相同会覆盖内置；换新 id 会追加。
- 只影响菜单栏排版，不改指标、HUD、主题。
- 菜单栏默认不显示獭图标（设置 → 菜单栏显示 → 显示獭图标）。

## 限制
手机菜单栏宽度预算 120pt：样式加名称/图标可能导致后面的指标被自动裁掉，
这是为了保证不顶到别的菜单项；选「纯数值」最省空间。
## 固定宽度与速率格式

- 菜单栏宽度按「当前启用指标的最坏情况数值」计算一次，数值变化时不再左右跳动。
- 速率在菜单栏使用紧凑写法（去掉 /s）：↑820K、↓1.5G；百分比补齐到 4 个字符。
- 上传/下载默认不勾选；勾选后会同时显示，不会被挤掉。
- 菜单栏样式切换或指标增减后，宽度会重新计算一次。
