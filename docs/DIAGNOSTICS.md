# 诊断与日志

设置 → 诊断与日志。

## 导出内容
- 版本、构建号、生成时间
- macOS 版本 / 架构 / 机型 / 已运行
- 磁盘可用 / 总量
- 实时指标（CPU/内存/磁盘/上传下载/核心数）
- 偏好（主题、HUD、菜单栏样式、通知、登录启动）
- 白名单与清理规则数量
- HUD / 菜单栏 / 清理规则的加载错误
- 最近 100 行内存日志（启动、结果卡等）
- ~/Library/Logs/DiagnosticReports 下 Otter 相关崩溃报告（文件名+时间）

## 行为
- 「保存诊断报告」：写到桌面（失败回退临时目录），并在 Finder 中显示。
- 「复制诊断文本」：复制到剪贴板。
- 全部本地生成，不上传任何数据。

## 自测
OTTER_SELFTEST=diagnostics：断言报告包含标题/版本/日志段落，输出字符数与崩溃报告数。
